**Config Headers**

This directory contains local headers consumed by the firmware build.

Current layout:

- `settings.h`
  Generated from `config/local/<board_id>.json` by `scripts/generate_settings_header.py`.
  Do not edit this file directly.

- `secrets.h`
  Local Wi-Fi credentials and any other private deployment secrets.

What does not belong here:

- Portable firmware defaults
  Those belong in `device_config.example.json` and the settings generator.

- Git build metadata
  Git branch / commit information is injected from `platformio.ini`
  `build_flags` so each compiled firmware can identify the source revision
  it came from.
